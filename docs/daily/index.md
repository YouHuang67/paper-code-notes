## 试点标签

当前试点页支持按以下维度组合筛选：

- **主题**：视频后训练、视频高效计算、拟合与蒸馏、奖励强化学习、VLM 调 PE 等。
- **论文单位**：企业/研究机构参与、高校参与、企业/研究机构+高校。分类以论文署名单位为依据，并在条目中展示单位名称；论文未列单位时标为“单位未列出”，不纳入三类参与筛选。
- **通用性**：通用方法、方向内通用、细分场景。
- **实验聚焦**：多数据集、多模型、多任务，或单一数据集/任务偏重。

后续日报沿用上述单位口径，标签从结构化字段生成并经人工核对作者单位证据。
