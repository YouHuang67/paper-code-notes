## 试点标签

当前试点页支持按以下维度组合筛选：

- **主题**：视频后训练、视频高效计算、拟合与蒸馏、奖励强化学习、VLM 调 PE 等。
- **机构组合**：大型机构独占、大型机构+高校/非大型机构、高校/非大型机构独占。分类以论文署名单位和机构层级表为依据，并在条目中展示单位名称；论文未列单位时标为“单位未列出”，不纳入前三类筛选。
- **覆盖面**：跨任务通用、任务内通用、细分任务；判定依据是方法作用范围和论文实验覆盖。

后续日报沿用上述单位口径，标签从结构化字段生成并经人工核对作者单位证据。
