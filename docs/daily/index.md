# 论文日报

日报按日期归档。每篇论文独立展示标题、作者、摘要、作者单位、研究问题、方法、实验范围、判断和证据。论文卡片按顺序平铺；主题以筛选标签显示，任务层级只分通用和垂类。

## 筛选维度

- **主题**：依据 `scripts/paper-daily.json` 中维护的范围进行筛选。
- **机构类型**：高校、企业、科研机构、个人、其他或待核实；联合署名条目支持按组合中的单一类型匹配。
- **层级**：通用或垂类，依据论文方法跨领域适用范围判断。

机构类型标签描述作者署名性质，不用于推断计算资源。详细字段和审核规则见 [日报规范](../design/daily-report-spec.md)。
