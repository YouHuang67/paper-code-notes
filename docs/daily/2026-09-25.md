## 视频生成与后训练

### Training Object Permanence in World Models

[arXiv:2609.28654](https://arxiv.org/abs/2609.28654)

**标签**：`视频后训练` `高校联合` `方向内通用` `多基准验证`

**问题**：视频世界模型能够生成视觉上连续的未来，但可能无法保持被遮挡物体持续存在，也无法稳定遵守固体碰撞关系。论文把 object permanence 与 solidity 作为可单独训练和评估的物理认知能力。

**方法**：构建 WROP 数据与 benchmark，使用 150 个手工设计的 Blender 生成器覆盖六类任务；通过随机化光照、视角、速度等干扰因素，保持任务结构不变，再用这些样本训练 continuation model。

**实验范围**：数据包含约 150 万训练样本、300 道评测题，并对 14 个视频生成模型进行比较；论文还报告 PWM-WROP continuation model 的结果。

**判断**：研究对象是视频世界模型中的物理一致性子能力，方法和基准具有方向内通用性，但结论主要围绕物体永久性与固体性展开。

</article>

<article markdown="1" class="daily-paper-card" data-tags="视频高效计算,产业研究机构,方向内通用,多基准验证">

### Accelerating Video Diffusion via Training-Free Trajectory Routing

[arXiv:2609.30096](https://arxiv.org/abs/2609.30096)

**标签**：`视频高效计算` `产业研究机构` `方向内通用` `多基准验证`

**问题**：视频扩散需要在多个去噪步骤反复执行大模型，即使采用 step distillation，单步模型评估成本仍高。

**方法**：TRACK 先用大模型生成参考轨迹，再在校准阶段比较大小模型在同一 latent、时间步、条件和 guidance 下的预测差异，形成按时间步的 disagreement map；低差异步骤路由到小模型，高敏感步骤保留大模型。

**实验范围**：在 Wan 2.1、Cosmos 3、TurboDiffusion 和 FastVideo 上分别报告 1.95×、2.04×–2.73×、2.69× 和 2.17× 加速，同时考察整体质量与多样性保持。

**判断**：这是不改训练、不改 scheduler 的视频扩散推理优化，跨多个模型族验证，属于视频生成方向内较通用的效率方法。

</article>

### AV-GRPO: Modality-Anchored Decoupling Diffusion Reinforcement Learning for Joint Audio-Video Generation

[arXiv:2609.29816](https://arxiv.org/abs/2609.29816)

**标签**：`视频强化学习` `产业研究机构` `方向内通用` `多基准验证`

**问题**：联合音视频生成同时面对单模态保真、文本对齐和跨模态同步；直接把异质奖励混在一起会造成信用分配不清，两个模态塔同时更新也增加训练成本。

**方法**：AV-GRPO 使用 modality-anchored rollout 将联合优化拆成条件单模态问题，用 trajectory-locked frozen-tower optimization 固定一侧塔，并按模态和样本难度调整目标与扰动强度；同时构建五维解耦的 5DAV 数据集。

**实验范围**：在 JavisBench 和 VABench 上，与 LTX-2.3 比较 LoRA 与 full fine-tuning 两种设置，并通过消融分析 anchor、冻结塔和自适应目标的作用。

**判断**：方法针对联合音视频生成，但信用分配和模态解耦思路可迁移到其他多模态后训练；当前证据集中在两个联合生成 benchmark。

</article>

## 语言模型拟合与蒸馏

<article markdown="1" class="daily-paper-card" data-tags="拟合与蒸馏,产业研究机构,通用方法,多基准验证">

### CataOPD: Catalytic On-Policy Distillation for Large Language Model Reasoning

[arXiv:2609.29518](https://arxiv.org/abs/2609.29518)

**标签**：`拟合与蒸馏` `产业研究机构` `通用方法` `多基准验证`

**问题**：RL 在没有采到正确轨迹时缺少正向信号，OPD 又受学生自身 on-policy 分布限制，难以触达学生原本不会生成的正确推理路径。

**方法**：CataOPD 把教师作为 catalyst 而非最终目标。Self-Rescue Routing 对全失败 rollout group 触发额外自采样；仍未解决的问题由 Catalytic-Guided Self-Resolution 引入教师引导，随后把验证过的学生轨迹内化。Barrier-Weighted Internalization 按 guided 与 unaided log-probability gap 对 token 加权。

**实验范围**：论文比较独立学生推理、教师引导和 catalyst-free inference，并评估分布外泛化；报告模型、任务和轨迹内化阶段的对比结果。

**判断**：核心贡献是把“教师帮助探索”与“学生最终独立推理”分开，适用于 LLM 推理后训练；其收益依赖验证轨迹和引导分布的构造。

</article>

<article markdown="1" class="daily-paper-card" data-tags="拟合与蒸馏,大公司参与,方向内通用,多基准验证">

### TS-OPD: Reconciling ASR and QA in Speech Language Models via Task-Specific On-Policy Distillation

[arXiv:2609.29464](https://arxiv.org/abs/2609.29464)

**标签**：`拟合与蒸馏` `大公司参与` `方向内通用` `多基准验证`

**问题**：语音识别专项化会提升 ASR，却可能损害预训练语言模型继承的问答和指令跟随能力。

**方法**：TS-OPD 使用 ASR 专项化前后的模型作为互补教师；学生分别生成 ASR 和 QA 条件轨迹，每类轨迹只接受对应教师监督，减少两种目标在同一 token 序列上的竞争。

**实验范围**：覆盖 basic ASR、contextual ASR 和 QA，并测试不同平衡系数与蒸馏数据规模下的稳定性。

**判断**：任务分流式 OPD 对多任务能力保持具有参考价值，但实验主体仍是语音语言模型，通用性标为方向内通用。

</article>

### Post-Training Leaves Behavioral Shadows on Unrelated Decisions

[arXiv:2609.29233](https://arxiv.org/abs/2609.29233)

**标签**：`拟合与蒸馏` `大公司参与` `通用方法` `多基准验证`

**问题**：后训练的影响可能不局限于训练任务本身；论文研究任务无关文本中是否存在可传递的能力更新信号。

**方法**：Active Taskless Distillation（ATD）选择教师与学生共同祖先在两个普通词之间近乎无偏好的 prompt，只保留教师输出的单词作为训练信号。学生不接触目标任务样本、教师 logits 或教师参数。

**实验范围**：在 Qwen2.5-1.5B coding 实验中使用 5,664 个单词响应，在 HumanEval+ 上相对配对打乱控制提升 5.34 个百分点；另测试科学知识、常识推理和阅读理解。

**判断**：论文提供了后训练行为可通过表面无关文本迁移的实验证据，属于训练信号和模型行为分析的通用问题。

</article>

### Not Every Token Is Worth Distilling: Selective Supervision for Direct-OPD

[arXiv:2609.29142](https://arxiv.org/abs/2609.29142)

**标签**：`拟合与蒸馏` `产业研究机构` `通用方法` `多基准验证`

**问题**：Direct-OPD 用 post-RL 与 pre-RL checkpoint 的 token-level log-ratio 在学生 rollout 上提供密集监督，但相对变化并不总能代表有用的行为变化。

**方法**：S2D-OPD 以教师与参考模型在状态上的 Jensen–Shannon divergence 排序，只保留每个 response 中 top 10% 的高差异状态施加监督，屏蔽低差异状态。

**实验范围**：覆盖两组 teacher pair 和 1.7B–8B 四个学生模型，在 AIME 与 HMMT 上比较 dense Direct-OPD；八组设置中七组提升，另一组持平，且不增加 forward pass。

**判断**：贡献集中于 OPD 监督状态选择，公式简单、额外开销低，属于可迁移的训练信号设计。

</article>

### From Self-Distillation to Self-Practice: Privileged Information for Multi-Turn Agents

[arXiv:2609.29051](https://arxiv.org/abs/2609.29051)

**标签**：`拟合与蒸馏` `大公司参与` `方向内通用` `多基准验证`

**问题**：多轮 agent 的 privileged information 能帮助教师判断行动，但学生在实际交互中无法持续获得这些信息，长程 rollout 可能产生误导性监督。

**方法**：论文比较 privileged-information self-distillation 与 self-practice，后者让 agent 通过自身交互、尝试和反馈积累可用经验，减少对不可部署特权上下文的依赖。

**实验范围**：围绕多轮 agent 任务比较两类训练路线，重点观察长程轨迹中的错误累积、任务完成和训练稳定性。

**判断**：结论直接针对 agent 后训练中的训练—部署信息落差，适用于长程交互任务；方法通用性受环境和反馈机制影响。

</article>

<article markdown="1" class="daily-paper-card" data-tags="拟合与蒸馏,产业研究机构,通用方法,多基准验证">

### LastOPD: Taming Collapse in Latent On-Policy Distillation

[arXiv:2609.28845](https://arxiv.org/abs/2609.28845)

**标签**：`拟合与蒸馏` `产业研究机构` `通用方法` `多基准验证`

**问题**：持续做 latent-state 对齐可能出现“早期提升、后期崩溃”：学生与教师表示更接近，但任务性能反而下降。

**方法**：LastOPD 只在两模型共同读取的 last-layer state 上施加 latent signal，并用 10-step crossfade 逐步切换到 token-level OPD，避免长期把学生拉向无法表达的教师中间状态。

**实验范围**：在 Qwen3-4B/8B 教师到 Qwen3-1.7B 学生的设置中，比较 MATH-500 与留出数据集；相对 token-only OPD，4B 和 8B 教师分别提升 5.55 和 4.02 个百分点，并约用一半步骤达到对照最终分数。

**判断**：论文把 latent supervision 的收益和失稳边界具体化，方法适用于 OPD 训练稳定性研究，但依赖可访问的模型隐状态。

</article>

## 音频与工具调用

<article markdown="1" class="daily-paper-card" data-tags="拟合与蒸馏,产业研究机构,方向内通用,多基准验证">

### Reward-Tilted On-Policy Distillation for Acoustic Grounding in Audio-Language Models

[arXiv:2609.28778](https://arxiv.org/abs/2609.28778)

**标签**：`拟合与蒸馏` `产业研究机构` `方向内通用` `多基准验证`

**问题**：音频语言模型可能依靠文本可预测性回答，而没有使用声音本身；普通 OPD 没有区分语言支持与声学支持。

**方法**：教师分别在有音频和无音频条件下预测同一学生文本，二者 log-probability 差值作为 reward，再用该 reward 重塑 reverse-KL 教师分布，使新增声学证据获得更大权重。

**实验范围**：覆盖两个 compact student 和三个 benchmark；在静音、替换音频测试中检查模型是否依赖声学证据，3B 模型在 MMAU 达到 72.72% accuracy。

**判断**：这是把模态贡献显式纳入 OPD 的方法，适用于音频 grounding；实验对象集中于音频语言模型。

</article>

<article markdown="1" class="daily-paper-card" data-tags="奖励强化学习,大公司参与,方向内通用,多基准验证">

### SLCA-GRPO: Resolving Cross-Segment Credit Misattribution in Tool-Calling RL

[arXiv:2609.29050](https://arxiv.org/abs/2609.29050)

**标签**：`奖励强化学习` `大公司参与` `方向内通用` `多基准验证`

**问题**：工具调用 agent 的输出同时包含结构化工具动作和自然语言摘要，GRPO 的轨迹级 advantage 会把摘要噪声传播到工具决策 token。

**方法**：SLCA 在同一 rollout group 内按结构片段估计 advantage，Hierarchical Rewards 将 execution advantage 分配给工具 token，将 preference advantage 分配给摘要 token；SGLS simulator 用于降低真实 API 探索成本。

**实验范围**：7B backbone 上相对 GRPO、ToolPO 和 RLTR，在 in-domain、BFCL 和 τ2-Bench 分别提升 2.53、1.36 和 9.15 个百分点，同时减少工具冗余与成本。

**判断**：方法解决的是 agent RL 中结构化动作与自然语言混合输出的信用分配问题，方向内通用性较强，且公司团队参与明确。

</article>

## VLM 调 PE

<article markdown="1" class="daily-paper-card" data-tags="VLM调PE,大公司参与,方向内通用,多基准验证">

### WanPE: Towards Cinematic Prompt Enhancement for Modern Text-to-Video Generation

[arXiv:2609.30221](https://arxiv.org/abs/2609.30221) · [项目页](https://wan-pe.github.io/)

**标签**：`VLM调PE` `大公司参与` `方向内通用` `多基准验证`

**问题**：长时程文生视频需要同时规划动作、镜头、光照、对白和声音；简单 prompt 改写难以保持多 shot 的语义与时间一致性。

**方法**：WanPE 用 1.05M 真实视频进行 video-grounded reverse construction，把用户请求映射为 shot-level cinematic plan；SC-GRPO 对风格、主体、动作、对白、声音、镜头、光照、空间关系和场景的一致性进行约束。

**实验范围**：WanPEval 覆盖 249 个请求、七类内容、5–30 秒、两种画幅和三种意图粒度，约 11K 次盲评；接入 Wan3.0 后，5–15 秒 preference 提升 10.66–18.84 点，30 秒提升 50.86 点。

**判断**：论文贡献是视频生成前的 cinematic planning，而非通用 LLM 对齐；数据覆盖多个视频内容和时长，属于视频生成方向内通用方法，不再单独展开机构分析。

</article>
