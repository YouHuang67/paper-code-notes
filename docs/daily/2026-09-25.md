### WanPE：面向现代文生视频的电影化提示词增强

**WanPE: Towards Cinematic Prompt Enhancement for Modern Text-to-Video Generation** · [arXiv:2609.30221](https://arxiv.org/abs/2609.30221) · [项目页](https://wan-pe.github.io/)

**标签**：`VLM调PE` `大公司参与` `方向内通用` `多数据集或多任务`

**机构判断**：Wan Team、Alibaba Group，联合南京大学、中国科学技术大学、复旦大学和清华大学。这里的“大公司参与”指论文首页/正文明确列出的公司团队，不是引用阿里模型或仅有项目致谢。

**为什么值得从日报刷出来**：普通 prompt enhancer 往往只是在原句上补形容词；WanPE 把任务改成“为视频生成器规划一段可执行的短片”。这使它连接了用户意图、视频生成器训练分布和长时程镜头一致性，是视频生成领域内相对通用的条件建模问题。

**核心问题**：设用户请求为 $x$，增强器生成条件为 $y$，视频生成器为 $G_\phi$。增强结果既要保持用户语义，又要落在视频生成器熟悉、能执行的条件分布中。论文将目标写成：

$$
p^*(y\mid x)=\frac{p_{vg}(y)\,\mathbf{1}[y\in Y_{sem}(x)]}{Z(x)}.
$$

其中 $p_{vg}(y)$ 是从真实视频得到的 video-grounded caption 分布，$Y_{sem}(x)$ 是不遗漏、不改写、不矛盾地满足用户请求的条件集合，$Z(x)$ 是归一化项。这个公式表达了论文的核心取舍：不能只追求“描述更丰富”，还要同时满足语义保真和下游生成可执行性。

**方法动机**：视频生成器训练数据里的 caption 通常已经对应真实拍摄或剪辑完成的视频，因此天然包含镜头顺序、动作推进、光照、声音和转场等结构。直接做 forward rewriting 只会围绕用户原句继续扩写，未必学到这些真实视频中的组织方式。WanPE 采用 video-grounded reverse SFT，从视频描述反向构造用户请求，再学习从请求恢复电影化条件。

**训练流程**：

1. 从视频片段生成层级化目标，包括视频级设定、shot 时间戳、主体动作、景别、镜头运动、光照、对白、音乐、音效和转场。
2. 用 reverse SFT 学习“简单请求 → 可执行电影化条件”。论文数据约 105 万个视频片段，覆盖十类内容。
3. 对同一请求采样多份增强结果，用 Semantic-Consistency GRPO（SC-GRPO）检查风格、主体、动作、对白、声音、镜头、光照、空间关系和场景等维度，惩罚遗漏、冲突和事件顺序错误。

**实验怎么看**：WanPEval 包含 249 个请求、七类内容、5/10/15/30 秒时长、16:9 和 9:16 比例，以及 intent、scene、shot 三种粒度；60 位相关专家进行约 1.1 万次匿名两两比较。WanPE-397B 在 Wan3.0 上相对原始请求显著提升人类偏好，5–15 秒子集总体 preference score 为 50.61，30 秒子集为 60.24；论文还在 LTX-2.5-Base 和 MiniMax-H3-Base 上做格式适配，观察跨生成器迁移。

**通用性与边界**：

- **不是完全通用的 LLM 方法**：训练和评测都围绕文生视频条件生成。
- **也不是单一小垂类**：数据覆盖多种视频内容和多个时长/画幅/请求粒度，目标是视频生成前的通用 prompt planning。
- **主要限制**：模型权重、配置和推理 API 尚未完整公开；公开网页更接近论文展示和预渲染 demo，而不是可直接调用的服务。

**日报判断**：`公司参与明确`、`视频方向内通用`、`实验覆盖较广`、`值得从日报进入深读`。

### Training Object Permanence in World Models

[arXiv:2609.28654](https://arxiv.org/abs/2609.28654)

**标签**：`视频后训练` `高校` `方向内通用` `单一数据集或任务偏重`

**研究动机**：视频世界模型可能生成外观连续、但物体穿透或性质不稳定的未来状态；论文把物体永久性和固体性作为后训练目标，关注生成视频是否遵守基本物理先验。

**方法与证据**：方法通过后训练让模型学习与物体持久存在、碰撞和固体约束相关的状态变化，再用世界模型视频预测评估物理一致性。日报摘要没有给出完整损失公式、数据规模和消融数字，因此这里不补写未核验的实验结论。

**边界判断**：这是视频世界模型物理一致性方向内的方法，问题有迁移价值，但实验重点集中在物体物理属性，暂不标为通用视频后训练方法。

</article>

### Accelerating Video Diffusion via Training-Free Trajectory Routing

[arXiv:2609.30096](https://arxiv.org/abs/2609.30096)

**标签**：`视频高效计算` `高校` `方向内通用` `单一数据集或任务偏重`

**研究动机**：视频扩散去噪的相邻步骤和相邻轨迹存在重复计算，完整执行每次模型评估会增加推理延迟。

**方法与证据**：TRACK 根据历史去噪轨迹判断哪些计算可以复用，并用路由机制跳过冗余评估；它不改训练流程，目标是直接降低推理成本。当前日报摘要未报告完整速度、质量和不同模型的数值对比。

**边界判断**：方法针对视频扩散推理，但“轨迹复用 + 自适应跳过”可作为效率优化范式继续观察；目前证据仍不足以判断跨架构稳定性。

</article>

### CataOPD: Catalytic On-Policy Distillation for Large Language Model Reasoning

[arXiv:2609.29518](https://arxiv.org/abs/2609.29518)

**标签**：`拟合与蒸馏` `高校` `通用方法` `多数据集或多任务`

**研究动机**：推理任务中正确轨迹稀缺时，RL 缺少正向学习信号；普通 OPD 又依赖教师在学生轨迹上提供有效监督，二者都会限制复杂推理训练。

**方法与证据**：CataOPD 用“催化”式教师信号推动学生从困难轨迹进入可学习区域，再进行 on-policy distillation；核心关注如何在没有现成正确轨迹时构造有效监督。当前日报摘要没有提供完整目标函数和实验数字。

**边界判断**：问题直接作用于 LLM 推理后训练，方法通用性高于单一应用；是否优于标准 OPD 仍需结合论文完整实验和数据规模判断。

</article>

### TS-OPD: Reconciling ASR and QA in Speech Language Models via Task-Specific On-Policy Distillation

[arXiv:2609.29464](https://arxiv.org/abs/2609.29464)

**标签**：`拟合与蒸馏` `高校` `方向内通用` `单一数据集或任务偏重`

**研究动机**：语音语言模型强化 ASR 能力后，可能损害问答和指令跟随；单一任务优化会造成能力迁移失衡。

**方法与证据**：TS-OPD 按任务特征设计 on-policy 蒸馏，让教师信号同时覆盖语音识别和问答行为，目标是在学生自身轨迹上调和两类能力。现有日报摘要没有给出数据集、模型规模和具体增益。

**边界判断**：核心矛盾可迁移到多任务后训练，但论文实验对象集中在语音语言模型，标记为方向内通用而非全局通用。

</article>

### Not Every Token Is Worth Distilling: Selective Supervision for Direct-OPD

[arXiv:2609.29142](https://arxiv.org/abs/2609.29142)

**标签**：`拟合与蒸馏` `高校` `通用方法` `多数据集或多任务`

**研究动机**：直接 OPD 对每个 token 使用相同监督权重，但不同 token 对学生学习的价值和风险并不相同。

**方法与证据**：论文选择性地对值得蒸馏的 token 施加 log-ratio 监督，减少无效或有害的教师更新；关键验证应关注 token 筛选准则、保留比例和与全 token OPD 的对比。

**边界判断**：方法直接改动 OPD 的监督粒度，具有通用方法属性；日报摘要未提供筛选阈值和完整消融，暂不对收益幅度下结论。

</article>

### From Self-Distillation to Self-Practice: Privileged Information for Multi-Turn Agents

[arXiv:2609.29051](https://arxiv.org/abs/2609.29051)

**标签**：`拟合与蒸馏` `高校` `方向内通用` `单一数据集或任务偏重`

**研究动机**：多轮 agent 训练中的特权信息可以帮助教师判断正确行动，但学生在长程交互中无法持续获得同样上下文，监督可能逐步失真。

**方法与证据**：论文比较特权信息驱动的在线自蒸馏与 self-practice 路线，重点考察多轮轨迹中的错误累积和监督可用性。摘要没有给出具体任务规模与数值结果。

**边界判断**：对 agent 长程后训练有直接参考价值，但任务结构和交互环境可能影响结论，暂列方向内通用。

</article>

### LastOPD: Latent-Space Supervision for On-Policy Distillation

[arXiv:2609.28845](https://arxiv.org/abs/2609.28845)

**标签**：`拟合与蒸馏` `高校` `通用方法` `多数据集或多任务`

**研究动机**：只对齐教师的下一 token 分布，可能无法约束学生内部推理状态，导致 OPD 在复杂推理中训练不稳定。

**方法与证据**：LastOPD 把监督扩展到隐空间，使教师信息不只作用于输出 token，还约束学生的中间表示；核心证据应比较隐空间监督、token 监督和训练崩溃率。

**边界判断**：这是蒸馏目标设计层面的通用尝试，但隐状态对齐依赖模型架构和可访问的内部表示，跨模型迁移条件需要额外验证。

</article>

### Reward-Tilted On-Policy Distillation for Acoustic Grounding in Audio-Language Models

[arXiv:2609.28778](https://arxiv.org/abs/2609.28778)

**标签**：`拟合与蒸馏` `高校` `方向内通用` `单一数据集或任务偏重`

**研究动机**：音频语言模型可能通过文本相关性而非声学证据完成回答，造成 acoustic grounding 不足。

**方法与证据**：方法在 on-policy 蒸馏中引入奖励倾斜，让教师预测监督与声学相关奖励共同影响学生生成，抑制文本捷径。日报摘要未给出奖励定义、数据集和增益数字。

**边界判断**：奖励与教师信号结合的思路可迁移到多模态对齐，但当前实验明显聚焦音频语言模型，暂列细分场景。

</article>
