# CoaG：用地面网格与圆柱体控制视频中的三维布局

- 论文：[arXiv:2609.24208](https://arxiv.org/abs/2609.24208)（v2，2026-09-23）
- 项目：[CoaG Project Page](https://zshyang.github.io/CoaG/)
- 作者单位：University of Washington。

## 概述

CoaG 研究视频生成中的低成本三维布局与相机控制。用户绘制地面网格，为每个人物放置并动画一个直立圆柱，同时设置相机路径；文本描述人物外观与动作，背景参考图提供场景背景。模型学习把这一简化几何控制信号映射到写实视频。其主要贡献包含控制表示、自动配对数据引擎，以及对 Wan2.2-Fun-Control 的 LoRA 适配。

## 控制表示与模型

控制视频固定为 81 帧、16 fps，黑色背景上渲染地面网格和人物圆柱。地面坐标系原点取首帧相机在地面的投影，前向轴为相机前向在地面平面上的投影，另一个轴由地面法线叉乘得到。网格间距取人物中位身高，使网格单元具有相对尺度含义。

每个人由一个直立圆柱表示，半径为身高的 0.2 倍；高度按片段首秒估计并保持固定。圆柱颜色按首帧人物从左到右分配，帮助跨帧维持身份对应和遮挡次序。控制渲染由此编码人物数量、左右顺序、地面位置、高度变化所对应的尺度关系、人物运动及相机运动。文本和背景图保留外观与场景语义的控制职责。

训练时，模型输入控制视频、背景参考图和文本，目标为源视频。底座采用 Wan2.2-Fun-A14B-Control，DiT 主干冻结，仅训练 LoRA；高噪声与低噪声专家分别使用独立 LoRA，切分点为噪声时间步 \(t=0.9\)。推理时用户绘制几何轨迹，经同一渲染程序生成控制视频，再与文本和背景图共同输入模型。

## 数据引擎

由于训练所需控制视频与真实视频成对数据缺失，作者从文本生成视频再反向恢复控制几何。caption 由组合式种子卡约束地点、地面、人物外观、动作和相机等维度，以提升覆盖。生成视频经过人物跟踪、背景修复、地面掩码提取、单目多视角重建与地平面拟合，最终把人物脚点和相机轨迹转换成圆柱与网格序列。

数据引擎最初处理 2,000 段视频，25 段因地面、平面或人物锚点硬失败被剔除，保留 1,975 段；其中 1,935 组用于训练，40 段留作 hold-out。论文报告数据完全来自自动生成流程，未使用真实视频和人工标注。附录统计了数量不匹配、轨迹跳变等软质量标记，说明训练样本存在自动恢复噪声。

## 实验与证据

留出测试显示模型能跟随人物数量、顺序、位置和高度等几何条件，并支持 dolly-in、orbit、pan、crane 等相机运动；dolly-out 控制较弱。作者还展示了更换文本描述来改变人物外观与动作、更换背景参考来改变环境，同时沿用几何布局的案例。

实验主要是定性展示与控制能力核验。论文明确说明没有开展人工用户研究、消融网格或定量对照评测。因此，结果支持表示与训练流程具备可行性，尚不足以量化其相对其他布局控制方法的优势幅度，也不能单凭示例断定复杂场景下的精确控制能力。

## 讨论与边界

圆柱表示人物占位与运动，不编码姿态、肢体动作、外形或人物间细粒度接触；相关细节由文本驱动的视频模型补全。数据生成流程依赖人物跟踪、地面分割、平面拟合及生成视频质量，自动恢复误差会传入控制监督。项目适合研究低维几何控制如何与外观生成解耦；目前的定性证据范围应与规模更大的定量基准工作区分。

## 可迁移设计点

- 网格同时提供场景尺度参照和相机运动线索，圆柱提供身份、位置和粗粒度动作表示。
- 合成训练对可通过可控 caption 组合设计覆盖维度，再用恢复质量标记跟踪噪声来源。
- 对控制方法应同时报告定量基准、人工评估与失效控制类型；定性示例适合说明能力，不替代比较实验。
