# CoaG：用地面网格与圆柱体控制视频中的三维布局

- 论文：[arXiv:2609.24208](https://arxiv.org/abs/2609.24208)（v2，2026-09-23）
- 项目：[CoaG Project Page](https://zshyang.github.io/CoaG/)
- 作者单位：University of Washington。

## 概述

CoaG 研究视频生成中的低成本三维布局与相机控制。用户绘制地面网格，为每个人物放置并动画一个直立圆柱，同时设置相机路径；文本描述人物外观与动作，背景参考图提供场景背景。模型学习把这一简化几何控制信号映射到写实视频。其主要贡献包含控制表示、自动配对数据引擎，以及对 Wan2.2-Fun-Control 的 LoRA 适配。

## 控制表示与模型

控制视频固定为 81 帧、16 fps，黑色背景上渲染地面网格和人物圆柱。地面坐标系原点取首帧相机在地面的投影，前向轴为相机前向在地面平面上的投影，另一个轴由地面法线叉乘得到。网格间距取人物中位身高，使网格单元具有相对尺度含义。

每个人由一个直立圆柱表示，半径为身高的 0.2 倍；高度按片段首秒估计并保持固定。圆柱颜色按首帧人物从左到右分配，帮助跨帧维持身份对应和遮挡次序。控制渲染由此编码人物数量、左右顺序、地面位置、高度变化所对应的尺度关系、人物运动及相机运动。文本和背景图保留外观与场景语义的控制职责。

训练时，模型输入控制视频、背景参考图和文本，目标为源视频。底座采用 Wan2.2-Fun-A14B-Control，DiT 主干冻结，仅训练 LoRA；高噪声与低噪声专家分别使用独立 LoRA，切分点为噪声时间步 \(t=0.9\)。推理时用户绘制几何轨迹，经同一渲染程序生成控制视频，再与文本和背景图共同输入模型。

## 数据引擎

由于训练所需控制视频与真实视频成对数据缺失，作者从文本生成视频再反向恢复控制几何。caption 由组合式种子卡约束地点、地面、人物外观、动作和相机等维度，以提升覆盖。生成视频经过人物跟踪、背景修复、地面掩码提取、单目多视角重建与地平面拟合，最终把人物脚点和相机轨迹转换成圆柱与网格序列。

数据引擎最初处理 2,000 段视频，25 段因地面、平面或人物锚点硬失败被剔除，保留 1,975 段；其中 1,935 组用于训练，40 段留作 hold-out。论文报告数据完全来自自动生成流程，未使用真实视频和人工标注。附录统计了数量不匹配、轨迹跳变等软质量标记，说明训练样本存在自动恢复噪声。

## 实验与证据

留出测试显示模型能跟随人物数量、顺序、位置和高度等几何条件，并支持 dolly-in、orbit、pan、crane 等相机运动；dolly-out 控制较弱。作者还展示了更换文本描述来改变人物外观与动作、更换背景参考来改变环境，同时沿用几何布局的案例。

实验主要是定性展示与控制能力核验。论文明确说明没有开展人工用户研究、消融网格或定量对照评测。因此，结果支持表示与训练流程具备可行性，尚不足以量化其相对其他布局控制方法的优势幅度，也不能单凭示例断定复杂场景下的精确控制能力。

## 讨论与边界

圆柱表示人物占位与运动，不编码姿态、肢体动作、外形或人物间细粒度接触；相关细节由文本驱动的视频模型补全。数据生成流程依赖人物跟踪、地面分割、平面拟合及生成视频质量，自动恢复误差会传入控制监督。项目适合研究低维几何控制如何与外观生成解耦；目前的定性证据范围应与规模更大的定量基准工作区分。

## 数据牌组与恢复管线

CoaG 的 caption 生成器从组合式种子牌组采样。牌组包含 50 个 region、162 个 ground archetype、118 个 action family、8 类相机运动、室外 12 类天气与时段、室内 6 类灯光、14 类环境运动元素，以及人物数量和运动范围等字段。人物数量按 1–6 人的六个桶分配，比例为 500、450、350、300、200、200 张；静态环境占 40%，带环境运动元素的样本占 60%。地点与地面组合由牌组控制，语言模型负责在给定组合中生成具体 caption。

生成视频经过以下恢复步骤：SAM 3.1 进行人物跟踪和地面掩码提取，LaMa 从首帧移除人物以得到背景参考图，HunyuanWorld-Mirror 在 10 个关键帧上恢复相机、点和法线，RANSAC 拟合地面平面，再用 GeoCalib 的地平线估计做一致性检查。人物脚点被提升到拟合平面，人物轨迹被转成圆柱轨迹；网格和圆柱由训练、推理共用的渲染器输出。

地面掩码使用最多三轮的 proposer–judge 循环：模型提出 1–3 个词的地面短语，SAM 3.1 对短语分割，人物掩码膨胀 10 像素后从地面掩码中扣除，小于画面 0.5% 的连通区域删除；judge 根据叠加图给出 accept、too_little、too_much 或 wrong_surface。三轮均拒绝时，流程采用画面下方 45% 的非人物像素作为 fallback，并记录 `ground_fail`。

## 训练与作者工具

底座是 Wan2.2-Fun-A14B-Control 的 control-ref 模式。训练将控制视频、LaMa 背景图和 caption 输入模型，目标为 81 帧视频；外部背景图替代训练视频首帧，避免背景参考直接暴露人物布局。两个专家各使用一个 LoRA，rank=64、alpha=32，作用于每个 block 的 query、key、value 与两个 FFN 投影。训练分辨率为 480×832，batch size 为每 GPU 1，使用 8 张 H100 80GB、AdamW、学习率 1e-4、weight decay 3e-2、gradient clipping 0.05、bf16、gradient checkpointing 和 ZeRO-2。推理使用 50 steps、CFG 6、LoRA weight 0.55，论文未测试更高分辨率。

作者工具允许用户放置 1–6 个圆柱、编辑 Bézier 轨迹、选择静态 tripod、pan、orbit、dolly、crane 等相机预设，并可用 GeoCalib 将相机拟合到背景照片的地平线。导出的 JSON 场景由同一渲染器转为控制视频，保证手工作者输入与训练条件的表示一致。

## 质量统计与证据边界

2,000 段生成视频中，ground fail 14、plane fail 7、anchor 缺失 5，共 25 段硬失败，剩余 1,975 段继续处理；其中 1,935 段训练、40 段 hold-out。软标记包括 count mismatch 658、track jump 508、anchor late 338、horizon disagree 316、feet cut later 162、bystanders 141 和 low camera 113。数量不匹配样本中，77 段少于 caption 要求的人数，374 段多出一到两人，207 段多出三人及以上。

论文的实验部分明确报告没有人工用户研究、消融网格或定量 controllability measurement。证据主要来自 hold-out、手工作者控制和 out-of-distribution stress tests 的均匀采样视频。该设计适合验证控制信号能否工作，定量比较能力仍需后续基准补充。单一地面平面限制了楼梯、多层台面和复杂地形；圆柱控制提供位置、身份和粗粒度运动，人物姿态、外观、接触和动作细节由文本视频模型完成。

## 可迁移设计点

- 网格同时提供场景尺度参照和相机运动线索，圆柱提供身份、位置和粗粒度动作表示。
- 合成训练可通过可控 caption 组合设计覆盖维度，再用恢复质量标记跟踪噪声来源。
- 对控制方法应同时报告定量基准、人工评估与失效控制类型；定性示例适合说明能力，不替代比较实验。
