# Coconut：连续潜在思维中的语言模型推理

> 论文：[Training Large Language Models to Reason in a Continuous Latent Space](https://arxiv.org/abs/2412.06769)，Hao 等，Meta FAIR 与 UC San Diego。本文依据论文正文和附录解读。

## 概述

Coconut（Chain of Continuous Thought）研究语言模型能否以连续隐藏状态承载推理步骤。模型在潜在模式中将最后一层隐藏状态直接反馈为后续输入嵌入，并以多阶段课程逐步替换 CoT 前缀。GPT-2 实验显示，Coconut 在 ProsQA 图搜索上达到 97.0%，高于 CoT 的 77.5%，平均生成 14.2 tokens；GSM8K 上为 34.1%，低于 CoT 的 42.9%。论文以候选概念分布和节点高度相关性支持“延后决策、逐步筛选”的搜索解释，当前证据主要来自规划型逻辑数据和小规模模型。

## 背景与问题

标准 CoT 将中间推理编码为词元序列。论文指出，部分 CoT 词元承担语言衔接功能，核心推理步骤则可能需要搜索与回溯。离散自回归生成在每一步都提交一个词元，早期选择会限制后续轨迹。Coconut 检验另一种状态表示：保留 Transformer 的可微计算，将连续隐藏向量直接交给后续前向，使状态无需先映射回词表。

论文的两个研究问题是，连续状态能否为多步推理提供有效监督，以及模型行为是否呈现并行保留候选的特征。第二个问题尤其重要，因为“潜在状态含有信息”本身不能推出搜索机制，作者还需要对 ProsQA 路径预测行为进行分析。

## 方法分析

设输入词元嵌入前缀为 $E_t=[e(x_1),\ldots,e(x_t)]$，Transformer 最后一层状态为 $h_t$，语言模型头为 $W$。普通模式通过 $\mathrm{softmax}(Wh_t)$ 预测下一个词元。Coconut 在 `<bot>` 与 `<eot>` 之间进入潜在模式，将 $h_i$ 作为下一前向的输入嵌入：

$$E_t=[e(x_1),\ldots,e(x_i),h_i,h_{i+1},\ldots,h_{t-1}].$$

潜在位置不映射成词元，也不计算这些位置的语言损失；`<eot>` 后恢复普通词元嵌入。模型的隐藏状态经过最终归一化后被反馈，避免直接使用未经归一化的残差幅度。潜在位置的训练目标由后续仍可见词元的交叉熵提供，模型因此学习对后续预测有用的表示。目标函数没有要求隐藏状态重建被替换的 CoT 文本。

课程训练从完整 CoT 开始。在第 $k$ 阶段，前 $k$ 个语言推理步骤被替换为 $k c$ 个连续思维，$c$ 是每个语言步骤对应的潜在步数。问题和潜在位置的损失被 mask，答案及保留的后缀继续接受 next-token loss；阶段切换时重置优化器状态。若插入 $n$ 个连续思维，训练需要依次生成这些状态并再运行一次预测前向，即总计 $n+1$ 次前向。KV cache 可以复用固定前缀计算，连续状态之间仍存在因果依赖。

推理时可固定潜在思维数量，也可训练二分类终止器。论文实验选择固定长度，以控制计算预算。逻辑任务使用 $c=1$，GSM8K 使用 $c=2$。此处的推理步数对应隐藏状态反馈次数，并不等同于输出词元数。

## 搜索解释

ProsQA（Proof with Search Question-Answering）把逻辑关系组织为自然语言描述的有向无环图，要求从实体沿有效边找到目标概念。图平均包含 23 个节点、36 条边，最短路径平均长 3.8，平均存在 1.6 条最短路径；数据集训练、验证、测试规模分别为 17,886、300、500。

作者在潜在思维后使用语言模型头探测概念的词表概率，并将其解释为隐式价值估计。示例中第一步最高分候选在后续状态中失去领先，另一条路径的后继获得更高分。总体分析显示，第一步 top-1、top-2、top-3 候选保留较大概率质量差距，第二步差距缩小；越接近终点的节点，正确与错误候选的分数越容易区分。上述结果与早期并行探索、后期集中选择的搜索行为一致。探针读取的是输出分布，不能直接观测隐藏状态中的离散搜索树。

## 实验结果

实验以 GPT-2 为基础模型，学习率 $10^{-4}$、有效 batch size 128。ProsQA 最多 6 个推理步骤，课程包括完整 CoT 初始阶段和 6 个逐步替换阶段；每个替换阶段训练 5 epoch，最终阶段继续训练至总计 50 epoch。ProntoQA 使用相同逻辑课程。GSM8K 使用 $c=2$，从初始阶段起依次替换 3 个 CoT 步骤，并增加固定 6 个连续思维的长尾阶段；初始阶段 6 epoch，其余阶段各 3 epoch。checkpoint 由验证准确率选择，推理采用 greedy decoding。

表 1 的结果如下。准确率以百分比计，长度是平均生成词元数：

| 方法 | GSM8K 准确率 / tokens | ProntoQA 准确率 / tokens | ProsQA 准确率 / tokens |
|---|---:|---:|---:|
| CoT | 42.9 ± 0.2 / 25.0 | 98.8 ± 0.8 / 92.5 | 77.5 ± 1.9 / 49.4 |
| No-CoT | 16.5 ± 0.5 / 2.2 | 93.8 ± 0.7 / 3.0 | 76.7 ± 1.0 / 8.2 |
| iCoT | 30.0* / 2.2 | 99.8 ± 0.3 / 3.0 | 98.2 ± 0.3 / 8.2 |
| Coconut | 34.1 ± 1.5 / 8.2 | 99.8 ± 0.2 / 9.0 | 97.0 ± 0.3 / 14.2 |

ProsQA 上 Coconut 比 CoT 高 19.5 个百分点，生成词元减少约 71.3%；ProntoQA 准确率相同，生成词元减少约 90.3%。GSM8K 上 Coconut 比 CoT 低 8.8 个百分点，仍比 No-CoT 高 17.6 个百分点，生成词元减少约 67.2%。因而最强结果集中在规划与路径搜索任务，数学题上的显式 CoT 仍有优势。

课程消融中，直接训练最终潜在阶段使 GSM8K、ProntoQA、ProsQA 准确率降至 14.4%、52.4%、76.1%。保留课程并移除连续思维后，三项结果为 21.6%、99.9%、95.5%；将潜在状态换成 pause token 时为 24.1%、100.0%、96.6%。这些对照表明，课程有助于训练稳定，连续状态相对额外占位计算在 ProsQA 上提供增益。附录在 A100、batch size 1 报告平均单样本延迟：Coconut 在 GSM8K、ProntoQA、ProsQA 分别为 0.09、0.11、0.15 秒，CoT 分别为 0.26、0.85、0.47 秒。

扩展实验将 Coconut 应用于 Llama 3.2-3B 和 Llama 3-8B 的 GSM8K，准确率从 No-CoT 的 26.0%、42.2% 提升至 31.7%、43.6%。该结果表明任务级微调可应用于较大底座，实验只覆盖一个基准，尚不能说明规模扩展规律。

## 证据边界

论文的主要证据来自 GPT-2、三项数据集及新建的 ProsQA。ProsQA 的图结构使搜索假设可以被路径指标检验，也使结论受到合成逻辑分布限制。BFS 解释由候选词表概率、代表性案例和节点高度相关性共同支持；实验没有直接干预候选状态，也没有从隐藏向量中恢复明确定义的多条路径。连续思维生成仍增加串行前向，论文提供了单样本延迟数据，但没有跨硬件吞吐、显存和并发服务对照。

后续工作可将路径级指标与潜在状态干预结合，检验候选保留是否对最终准确率具有因果作用；还需在更大语言模型、更广任务分布和更完整推理成本下验证课程与固定长度策略。

## 可迁移设计点

1. 以未来词元预测训练潜在状态，避免人为规定每个隐藏状态对应的文字语义。
2. 通过逐阶段替换 CoT 前缀，把离散监督平滑过渡到连续状态反馈。
3. 对搜索任务同时评估最终答案、路径有效性与候选概率变化。
4. 将潜在思维次数与准确率、延迟和输出长度联合报告。

## 后续路线关联

Coconut 展示以连续隐藏状态替代部分语言 CoT 的任务级训练路径，尤其在 ProsQA 路径搜索上呈现候选延迟收敛现象。后续 looped Transformer 工作把额外状态变换组织为共享参数的重复深度；PonderLM-2 将 latent thought 纳入预训练目标并用 Jacobi iteration 实现训练并行；LoopFormer 进一步研究循环轨迹长度变化下的预算适配。这些工作与 Coconut 共用连续状态推理这一问题背景，各自的模型结构、监督和实验规模仍应单独评估。
