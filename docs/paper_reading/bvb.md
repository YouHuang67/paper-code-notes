# BVB：用 Blender 程序重建视频以评测时空理解

- 论文：[arXiv:2609.15478](https://arxiv.org/abs/2609.15478)（v3，2026-09-26）
- 代码：论文首页提供 GitHub 链接；本文按论文正文和附录解读。
- 作者单位：University of Rochester、Sony Group Corporation、Carnegie Mellon University、University of Washington；作者单位以论文首页为准。

## 概述

BVB（Blender-VideoBench）把视频理解转换成可执行场景重建：多模态 agent 观察视频帧，在 Blender 沙箱中编写 Python 场景程序，输出包含几何、动画和相机运动的 `.blend` 场景。论文的核心判断是，问答正确率可能由单帧线索或答案先验支撑；从视频恢复可渲染场景则同时要求空间布局、物体关系和时间变化信息。BVB 因此以重建结果作为视频理解能力的外显产物，并分开度量语义事实保留与视觉相似度。

## 任务与评测设计

基准沿用 VSI-Bench 的 288 段第一人称室内视频及 5,130 个空间、时间问答。每个 agent 在统一 Mini-BVB harness 中只获得两类工具：查看指定视频帧、在 Blender 容器运行代码。容器无网络，限制为 2 CPU、4 GB 内存，每个场景预算上限为 3 美元；禁止外部素材库。agent 需从基础几何体构造场景、设置相机轨迹并保存原生 Blender 文件。无法产生可渲染文件的样本在各项指标记零，评估流程不会对失败样本作选择性剔除。

评测包含两个互补量：

1. **Dual VQA（DV）**：对源视频和重建视频询问相同的空间及时序问题。只把裁判在源视频上答对的问题纳入可恢复事实集合，再统计重建保留比例。这样分母对应裁判确实识别到的源事实。
2. **Latent Similarity（LS）**：用冻结的 V-JEPA 2.1 表征比较源视频与渲染视频的潜在相似度，反映整体外观与运动表征接近程度。

论文将两者归一化到 0–100，并用平方根均值构造 Overall。令 \(A=\{DV,LS\}\)，其定义为：

\[
O=\left(\frac{\sqrt{DV}+\sqrt{LS}}{2}\right)^2.
\]

该聚合式等于两轴算术平均减去平方根分数的跨轴方差，因此会惩罚两轴不均衡。论文同时报告 DV 与 LS，避免总分掩盖具体短板。

## 实验结果

作者评测 10 个模型家族的 51 种配置。总体分数范围为 47.50–70.07；最高配置 GPT-6-Astra-high 达到 Overall 70.07、LS 88.6、DV 53.7。DV 对应 1,827 个源视频上被裁判正确回答的问题中，有 981 个事实在最佳重建中仍被保留，846 个未被保留。由此可见，生成结果在视觉表征上接近源视频时，仍可能遗漏场景数量、相对位置或事件次序等明确事实。

各问题类型的平均保留率也呈现差异：物体尺寸为 63.0%，路线规划为 58.5%，物体计数为 29.3%，出场顺序为 16.1%。这说明时间跨度更长或需要穷举场景实体的问题更难。成本分析中，最佳 Overall 配置每场景成本为 1.258 美元；GLM-5.3-Flash-xhigh 用 0.024 美元达到最佳配置 91% 的 Overall，呈现出可观的成本—质量折中。15 名人工评审对五个配置的盲排结果与 Overall 排序一致；这是对该小规模配置子集的验证，不代表自动指标对所有场景完全可靠。

## 方法解读与证据边界

DV 与 LS 测量对象不同：DV 检查可明确回答的语义事实是否存在于重建中，LS 检查整体视频表征接近程度。两轴并列有助于定位视觉相似度与细节事实保留率之间的差距。DV 依赖 VLM 对源视频问题回答正确这一筛选步骤，因此度量的是裁判可恢复事实的保留率；它覆盖源视频真值的范围受裁判能力影响。LS 使用预训练视频表征，对小物体身份或精细关系的敏感度也有限。

基准覆盖的是第一人称室内视频，且限制外部素材，促使 agent 以基础几何表示复杂场景。结果对这类视频理解与程序重建任务有直接参考价值；迁移到室外、长镜头、大规模动态物体或可调用素材库的设置时，需要重新验证任务难度和指标行为。

## 实验配置与补充分析

BVB 使用零样本 agent 评测，不对被测模型进行微调。Mini-BVB 的 `frames` 动作用时间戳或均匀帧数请求源视频，`bash` 动作用于在容器内执行 Python、Blender 和渲染命令。模型自行决定观察多少帧以及何时修改程序，实验约束由统一系统提示、容器和每场景成本上限给出。评测阶段将 `.blend` 文件用 EEVEE 渲染，再进入 DV 和 LS 计算；重建阶段与评分阶段隔离，评分器不会把反馈返回 agent。

LS 将 V-JEPA 特征拆成 Layout 与 Motion 两部分，分别刻画空间安排和时序动态，再取二者平均。它使用未在 BVB 上微调的冻结编码器，因此对 benchmark 的适配程度较低。DV 以均匀采样帧回答 VSI-Bench 问题，问题类型包括 object count、absolute distance、object size、room size、relative distance、relative direction、route plan 和 appearance order。最佳配置在表中对应的逐项 DV 为 48.5、33.5、73.7、33.1、49.0、50.0、54.8 和 36.0，平均为 53.7。

作者进一步比较模型间重建视频的相似度与事实集合重叠度。18 个配置形成的 153 个模型对中，视频表征平均相似度为 0.88，保留事实的 Jaccard 重叠为 0.45；同一模型家族的外观相似度为 0.91，跨家族为 0.88，而事实重叠只从 0.45 变为 0.46。这组结果说明外观收敛速度高于事实保留的一致性。

推理强度主要提高 LS，DV 的提升较小。成本与运行时间也没有单调决定 Overall：最佳配置每场景约 1.258 美元，GPT-5.6-Sol-xhigh 以 0.778 美元达到最佳分数的 96%，GLM-5.3-Flash-xhigh 以 0.024 美元达到 91%。人工盲排使用 5 个配置、每个 9 个场景，平均排序与 Overall 排序完全一致，场景和模型层面的偏好与 LS 相关性为 0.83。

## 复现条件与限制

复现需要同一版本的 V-JEPA 2.1、VLM judge、VSI-Bench 问题、EEVEE 渲染设置和 Mini-BVB 工具协议。基础几何重建对复杂材质、透明物体和细粒度纹理的表达能力有限；资产禁用规则强化了时空结构要求，也改变了任务与常规视频生成的关系。DV 的分母是裁判在源视频上识别出的可恢复事实，LS 的敏感度由冻结表征决定；两者均属于代理指标。论文的人工验证规模较小，主要验证自动排名趋势。

## 可迁移设计点

- 把问答任务转换为可执行产物，能同时检查空间结构、对象组合与时间变化。
- 语义事实与感知相似度分开报告，并公开失败样本处理规则，可减少单一综合分的解释歧义。
- 预算、沙箱和工具权限属于基准定义的一部分；跨模型比较应保持这些条件一致。
