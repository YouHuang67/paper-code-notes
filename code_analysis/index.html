    项目分析

    • CuTe sgemm_sm80 实战拆解 - 三版本对比、Swizzle SMEM、TiledCopy/TiledMMA、ldmatrix retiling、双层流水线
    • Flash Attention V2 - FA2 SM80 CUDA 实现：CuTe + CUTLASS 2.x 的 tiling attention 完整拆解（前向/反向/调度）
    • Native Sparse Attention - 硬件友好的稀疏注意力 Triton 实现
    • xformers Memory Efficient Attention - Split-K Triton 前向推理内核（mask 融合 + 量化）
    • CUTLASS Memory Efficient Attention - PyTorch ATen CUTLASS 前向 kernel（Online Softmax + 模板分发）
    • CUB Block 级原语 - BlockRadixSort 与 BlockScan 内部实现详解
    • FlashInfer Variable Block Sparse Attention - 本地剥离版 variable_block_attn：从 variable block 稀疏描述到 FA2 paged prefill 执行路径的完整代码拆解
    • PISA - Piecewise Sparse Attention：Triton 块统计预扫描、exact/zero-order/global first-order 三阶段前向与 GPU 负载均衡分析
    • MInference - Dynamic Sparse Attention Prefill：离线 pattern 搜索、Vertical-Slash CUDA 索引转换与 Triton mixed sparse attention kernel
    • SVOO - 离线 sparsity profile、低内存 Q/K co-clustering、dynamic map 预算生成、Triton fallback 与 FlashInfer variable block sparse plan patch
    • FastVideo VSA - FastVideo 中 VSA 的完整执行链：tile metadata、Triton coarse selector、64/256 sparse backend 与 TK/CuTe 路由
    • 框架接入、Tile Metadata 与门控 - 3D tile 重排、variable block size、sequence parallel、gate_compress 与论文到实现的映射
    • Triton Coarse Selector - fused_block_mean 与 fused_topk_mask 的程序布局、数值路径与寄存器边界
    • Sparse Backends - 64-token Triton/TK sparse attention、256 route-A 与 CuTe DSL block-sparse fastpath
    • Kernel Execution Appendix - 按源码执行顺序展开 q2k/k2q 索引、Triton sparse loop、Hopper CTA 内部状态与 256 路径图展开
    • MiniMax H3 - 统一多模态音视频生成主干：packed multimodal sequence、3D MM-RoPE、per-row AdaLN 与双 scheduler 推理链
    • 模型结构 - 单流 Omni Transformer、text refiner、共享 block stack 与双输出头
    • 推理流程 - Qwen3-VL presentation、layout packing、row timestep plan、双模态 denoise loop
    • 优化与实现细节 - mixed precision、context parallel、anchor rows、双 scheduler 与可复现协议
    • 如何嵌入 SGLang 体系 - H3 在 SGLang 中不是 generic diffusers fallback，而是 native pipeline / native DiT runtime / native packed-row contract
    • MiniMax H3 在 SGLang 中的效率主线 - 只抓 H3 最高价值的效率来源：单分支 packed DiT、persistent row buffer、fused AdaLN/QKNorm/RoPE、Ulysses/Ring 与 late gather
    • DiT Runtime 与 Collectives - 沿 _embed -> block -> attention core -> gather 主热路径细读 SGLang native H3 runtime，拆清 row-local staging、fused block dataflow 与 SP/TP collectives
    • Denoise Loop 状态机 - 单独拆开 MiniMaxH3DenoiseBranch、静态/动态状态、unique_timesteps/inverse_indices/block_combined_indices 与 target-row 增量更新
    • 效率附录 - 承接正文外的实现补充：关键文件地图、BCG prompt bucketing 与不同 GPU 拓扑的取舍
    • DeepSeek V4 - mHC + Hybrid Attention + MoE + TileLang 低精度推理实现
    • DeepEP - MoE Expert-Parallel 通信库：基于 TMA + NCCL Gin 的全 GPU 端 all-to-all 实现
    • DeepGEMM - Hopper/Blackwell JIT GEMM：分层内核、SM90/SM100 流水、grouped GEMM 接入标准 MoE
    • 分层内核架构 - layout / scheduler / mma / epilogue / impl 与 persistent 角色分工
    • SM90 到 SM100 流水 - WGMMA、UMMA/TMEM、TMA multicast 与 2SM
    • grouped GEMM 与标准 MoE 契约 - contiguous/masked、FP8/BF16 分叉、permute–SwiGLU–finalize
    • Mega MoE 与 paged MQA - 共享 token 池与 metadata 驱动的 indexer 流水
    • ELF - Embedded Language Flows: JAX/Flax DiT + Flow Matching + 共享权重 denoiser-decoder
