# 论文日报主题

每日推送读 `paper-daily.json`。分类不靠 arXiv 关键词，由 DeepSeek 按每条 `scope` 判断论文对象。微信正文由 `scripts/paper_daily.py` 生成。定时是北京时间工作日 9:30，命令是 `python3 scripts/paper_daily.py run`。

## 添加主题

只改 `paper-daily.json`，在 `topics` 追加一条：

```json
{
  "name": "主题名",
  "scope": "对象必须是……。哪些不算。",
  "enabled": true
}
```

`name` 是微信里【】中的标题，也是模型必须原样返回的主题名。`scope` 用一句话写清对象，再写不收什么。不要把范围写成一串或关键词。

改完后用一天 `--dry-run` 看归类，确认再发。不要把 `refs/scans/`、`refs/papers/`、`refs/research/` 的抓取结果提交进 git。

## 归类规则

模型每次看到论文标题和摘要前 280 字。每篇最多一个主题，每个主题最多 8 篇。句子保留英文术语，中文只补方法和判断。解释里要写「非」或「不是」的论文丢掉，脚本会再滤掉这种句子。没有论文的主题合成一行「无更新」。

## 版式

消息以 `[论文]` 开头。日期、【主题】、每条「— 句子」各自成段，段之间空一行。主题用全角【】，论文用长横线。不要用圆点。

## 当前主题

范围以 `paper-daily.json` 的 `scope` 为准。视频类是视频后训练、视频高效计算、视频强化学习、视频奖励、VLM调PE、信息图后训练。语言模型类是拟合与蒸馏、样本偏好、奖励强化学习、注意力现象、训练信号。
